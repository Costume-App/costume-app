# Training Video 4 (Costume Creations) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Script, record, build, and QC video 4, "Costume Creations": adding costume pieces to a role, reference photos and notes, choosing make or purchase, assigning makers, the Costume Creations page with its fabric fields and skirt yardage, automatic fabric estimates, the cost total, and logging a finished piece into House Inventory.

**Architecture:** Same recipe as videos 2 and 3. Every section's prep rebuilds the demo org's "Twelfth Night" to the state the viewer saw at the end of the previous section, through `resetTwelfthNight` in `lib/demo-productions.mjs`, now extended with costume designs and pieces. Two org-wide things this video needs, makers and House Inventory items, are touched only by exact name through a new `resetDemoCostumeOrg` helper, so repeated takes never pile up duplicates. The reference photo filmed on camera is a synthetic costume sketch generated by a repo script, handed over through Playwright's `filechooser` event. The fabric estimate is a live AI call, guarded so a bad or empty result is never filmed.

**Tech Stack:** Node ESM scripts, Playwright 1.63, ffmpeg/ffprobe (no `drawtext`), edge-tts in `~/.venvs/edge-tts`, Vitest (`scripts/**/*.test.mjs` and `src/**/*.test.ts`), the app's API as the demo user.

**Spec:** `docs/superpowers/specs/2026-09-22-training-videos-design.md` (video list item 4). Also read `docs/training-videos/README.md`, `docs/training-videos/followups.md`, `docs/superpowers/plans/2026-09-24-training-video-3-measurements.md` (its Task 4 is the model for Task 5 here), `scripts/lib/walkthroughs/measurements.mjs`, and `~/.claude/skills/recording-app-training-videos/lessons.md` before any walkthrough work.
